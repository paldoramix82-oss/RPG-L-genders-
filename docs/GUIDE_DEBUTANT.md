# Guide du débutant — LEGENDERS RPG

Ce guide est fait pour quelqu'un qui **n'a jamais joué à un jeu de rôle**. Pas besoin de connaître Donjons & Dragons : en 10 minutes de lecture, vous pouvez lancer votre première partie.

> Ce guide décrit la version actuelle du jeu. Il sera mis à jour à chaque amélioration (voir `PLAN_REFONTE.md`).

---

## 1. C'est quoi, ce jeu ?

C'est une **histoire que l'on raconte à plusieurs**, comme un film dont vous êtes les héros.

- **Un joueur est le Maître du Jeu (MJ).** Il joue sur le PC. Il décrit le monde (« Vous arrivez devant une auberge en ruine, il pleut… »), fait parler les personnages qu'on rencontre et décide de ce qui arrive.
- **Les autres sont les joueurs.** Chacun joue sur son téléphone et incarne **un personnage** qu'il a créé : un guerrier, une assassin, un mage…
- **Il n'y a pas de bouton « gagner ».** Le but est de vivre une aventure ensemble : explorer, discuter, se battre, résoudre des mystères.
- **Le jeu fait les calculs à votre place** : dés, dégâts, points de vie. Vous, vous racontez ce que fait votre personnage.

La règle d'or : **vous pouvez tenter n'importe quoi**. Si aucun bouton ne correspond à votre idée, écrivez-la. Le MJ décide comment ça se passe.

---

## 2. Ce qu'il vous faut

- Un **PC Windows** (pour le MJ) avec le jeu installé. Un téléphone Android peut aussi héberger, mais le PC est plus confortable.
- Un **téléphone Android** par joueur, avec l'application installée.
- **Le même Wi-Fi pour tout le monde.** (La 4G ne marche pas : il faut être sur le même réseau.)
- Compter **1 h 30 à 3 h** pour une partie.

---

## 3. Lancer la première partie (5 minutes)

### Le MJ, sur le PC
1. Ouvrez le jeu → **Héberger une partie**.
2. Dans **Nouvelle campagne**, donnez un nom, choisissez un **univers** (« Fantasy classique » pour commencer : il contient une petite aventure prête, *Les Cendres de Valombre*), puis **Créer la campagne et ouvrir la partie**.
3. Si Windows demande l'autorisation du pare-feu : acceptez pour les **réseaux privés**.
4. En haut à gauche, la carte **Pour rejoindre** affiche une **adresse IP** en grand (par exemple `192.168.1.20`). Donnez-la aux joueurs.

### Chaque joueur, sur son téléphone
1. Ouvrez le jeu → **Rejoindre une partie**.
2. Si la partie apparaît dans **Parties sur ce Wi-Fi**, touchez-la. Sinon, tapez votre **nom** puis l'**adresse IP** donnée par le MJ avec le pavé numérique, et touchez **Rejoindre la partie**.
3. Créez votre personnage (voir la section suivante).
4. Vous arrivez dans le salon **« Vous êtes prêt ! »** : attendez les autres.

### Le MJ lance
Quand la barre du haut indique que tout le monde est prêt, le MJ appuie sur **« La partie commence ! »**. C'est parti.

---

## 4. Créer son personnage (4 étapes)

Le jeu vous guide. Si vous hésitez, prenez les choix proposés par défaut : ils sont équilibrés.

**Étape 1 — La classe.** C'est le « métier » de votre personnage. Elle donne ses capacités et son équipement de départ.

| Si vous aimez… | Prenez |
|---|---|
| foncer et encaisser les coups | **Guerrier** |
| frapper vite, en douce, faire des coups critiques | **Assassin** |
| lancer des sorts | **Mage** |
| soigner et protéger les autres | **Prêtre** |
| tirer à l'arc de loin | **Rôdeur** |
| parler, charmer, aider le groupe | **Barde** |

(L'univers Légenders propose ses propres classes : Briseur, Ombre, Invocateur, etc. Chaque carte de classe explique son rôle en une phrase.)

**Étape 2 — Les points.** Votre personnage a 6 caractéristiques. Plus le chiffre est haut, meilleur il est dans ce domaine :

| Caractéristique | En clair |
|---|---|
| **Force** | taper fort, porter, enfoncer une porte |
| **Agilité** | viser juste, esquiver, être discret |
| **Endurance** | avoir beaucoup de points de vie |
| **Intelligence** | savoir, comprendre, magie de savoir |
| **Perception** | remarquer les détails, viser de loin |
| **Charisme** | convaincre, mentir, impressionner |

Vous avez **12 points** à répartir avec les boutons **−** et **+**. Baisser une caractéristique vous rend des points. Pas d'idée ? Touchez **Répartition conseillée**.

**Étape 3 — L'équipement.** Choisissez votre arme parmi celles de votre classe. Chacune indique ses **dégâts** (par exemple `1d8` = un dé à 8 faces), sa **portée** (en cases) et son **critique** (le résultat de dé qui double les dégâts).

**Étape 4 — Qui êtes-vous ?** Un nom, une couleur pour votre pion, une petite description si vous voulez.

Tout le reste (points de vie, défense, vitesse) est **calculé automatiquement**. Vous pourrez tout modifier plus tard dans l'onglet **Fiche**.

## 5. Comment on joue

### L'écran du joueur (5 onglets en bas)

| Onglet | À quoi il sert |
|---|---|
| **Carte** | le plateau de jeu avec les pions, comme un Monopoly. Le vôtre est entouré. |
| **Aventure** | l'histoire racontée par le MJ, les messages, les jets de dés. C'est là que vous écrivez. |
| **Fiche** | votre personnage : points de vie, attaques, capacités, inventaire. |
| **Groupe** | les autres personnages, le volume de la musique. |
| **Codex** | l'encyclopédie du monde, si vous êtes curieux. |

### Parler et agir (onglet Aventure)
En bas de l'onglet Aventure, trois boutons :
- **Message** : parler au groupe, ou **au MJ en privé** (les autres ne le voient pas).
- **Action** : décrire ce que vous tentez. *Exemples : « Je fouille le bureau du maire », « J'essaie de convaincre le garde de nous laisser passer », « Je grimpe sur le toit pour voir plus loin ».* Le MJ répond, et vous demande parfois de **lancer un dé**.
- **Dés** : lancer des dés vous-même si le MJ vous le demande.

Parler ne coûte rien : vous pouvez discuter à tout moment, **même pendant un combat**.

### Les phases de jeu
Le MJ choisit le rythme de la partie. Le nom de la phase est écrit au-dessus de la carte.

| Phase | Ce qui se passe |
|---|---|
| **Récit libre** | Tout le monde agit quand il veut. |
| **Exploration** | Chacun son tour : on avance son pion, on fait une action, puis **Fin du tour**. |
| **Dialogue** | Chacun son tour, sans bouger. |
| **Combat** | Chacun son tour, dans l'ordre de rapidité (l'« initiative »). |
| **Repos** | On récupère : à la fin, chacun regagne la moitié de ses PV et toute son énergie. |

Quand c'est à vous, **votre téléphone vibre** et affiche **« C'est votre tour ! »**.

### Votre tour, pas à pas
1. **Bouger** : les cases où vous pouvez aller **brillent en doré**. Touchez-en une.
2. **Agir** (une seule action) :
   - **Attaquer** : choisissez votre arme, puis touchez l'ennemi. Le jeu lance le dé pour vous.
   - **Capacité** : un pouvoir de votre classe (soin, sort, coup spécial). Il coûte de l'énergie.
   - **Objet** : boire une potion, etc.
3. Touchez **Fin du tour**. C'est au suivant.

### Les dés, en 30 secondes
- `d20` = un dé à 20 faces (résultat de 1 à 20). `2d6` = deux dés à 6 faces additionnés. `+3` = on ajoute 3.
- Pour **réussir** quelque chose, il faut atteindre un nombre (la « difficulté ») : 10 c'est facile, 15 c'est moyen, 20 c'est très dur.
- Pour **toucher** un ennemi, il faut atteindre sa **Défense**.
- **20 naturel** (le dé montre 20) : réussite automatique. **1 naturel** : échec automatique.
- **Critique** : un très bon résultat double les dés de dégâts.
- Les dés sont lancés par le PC du MJ : personne ne peut tricher, pas même le MJ par erreur.

### Les points de vie (PV)
Quand vous êtes touché, vos PV baissent. À **0 PV**, votre personnage est **hors de combat** (son pion devient gris). Il n'est pas forcément mort : c'est le MJ qui raconte la suite. Le repos et les soins font remonter les PV.

## 6. Guide express du MJ

Vous n'avez pas besoin d'être un conteur professionnel. Voici une recette pour une première soirée réussie.

### Avant de commencer (10 minutes)
- Prenez l'univers **Fantasy classique** : la carte de Valombre, ses habitants et ses secrets sont déjà prêts.
- Dans **Personnages → Packs de PNJ…**, importez *Les Cendres de Valombre* et *Bestiaire et adversaires* : vous aurez des personnages et des monstres prêts à placer.

### Pendant la partie
1. **Ouvrez la scène** dans l'onglet **Récit** : « Vous arrivez à Valombre à la tombée de la nuit. Les cloches sonnent alors qu'aucune messe n'est prévue… »
2. **Demandez aux joueurs ce qu'ils font.** Mettez la phase **Exploration** pour que chacun joue à son tour, ou **Récit libre** si la scène est détendue.
3. **Répondez aux actions** : quand un joueur déclare une action, elle apparaît dans **Récit**. Vous pouvez la résoudre directement, la refuser, ou cliquer **« Le joueur lance »** pour lui demander un dé (par exemple `d20`, difficulté 12).
4. **Pour un combat** : placez des monstres sur la carte (outil **Pion**, ou depuis une fiche de PNJ), puis choisissez la phase **Combat**. L'ordre des tours se calcule tout seul et la musique de combat démarre. Quand c'est le tour d'un monstre, ses boutons d'attaque apparaissent dans la carte **Phase de jeu** : choisissez l'attaque, puis la cible.
5. **Après le combat** : phase **Repos**, puis reprenez l'histoire.

### Trois conseils
- **Dites « oui, mais… »** plutôt que « non ». Un joueur veut sauter par la fenêtre ? D'accord, mais il se blessera peut-être (jet de dé).
- **Donnez la parole à tout le monde**, surtout aux plus timides.
- **Ne vous bloquez pas sur les règles.** Si vous hésitez, décidez et continuez : l'histoire compte plus que le calcul.

### Les outils à connaître
- **Carte « Phase de jeu »** (en haut à droite) : changer de phase, voir l'ordre des tours, faire jouer les monstres, **Tour suivant**.
- **Carte « Ambiance musicale »** : choisir la musique (taverne, exploration, combat…).
- **Onglet Personnages** : toutes les fiches. Vous pouvez tout modifier (PV, objets…).
- **Bouton Jet** à côté d'un joueur : lui demander un jet (« Perception, difficulté 12 »).
- **Sauver** : la partie est aussi sauvegardée automatiquement chaque minute. La prochaine fois, choisissez **Reprendre** dans l'écran d'hébergement.

## 7. Petit lexique

| Mot | Sens |
|---|---|
| **MJ** | Maître du Jeu : celui qui raconte et arbitre. |
| **PNJ** | Personnage Non Joueur : tous les personnages joués par le MJ (aubergiste, méchant…). |
| **PV** | Points de Vie. |
| **Énergie / AEC / mana** | La réserve qui sert à utiliser les capacités. |
| **Défense** | Le nombre à atteindre au dé pour vous toucher. |
| **Initiative** | Votre rapidité : elle décide qui joue en premier en combat. |
| **Jet** | Lancer de dés. |
| **Difficulté** | Le nombre à atteindre pour réussir un jet. |
| **Critique** | Coup particulièrement réussi : dégâts doublés. |
| **Phase** | Le rythme du moment (exploration, combat, repos…). |
| **Tour** | Le moment où c'est à vous de jouer. |

## 8. Problèmes fréquents

| Problème | Solution |
|---|---|
| « Le PC du MJ ne répond pas » | Vérifiez que le téléphone est sur **le même Wi-Fi** que le PC (pas en 4G) et que l'adresse IP est bien recopiée. Sur le PC, autorisez le jeu dans le pare-feu Windows (réseaux privés). |
| « Version du jeu différente » | Le PC et le téléphone n'ont pas la même version : réinstallez la bonne. |
| Le téléphone a perdu la connexion | Il se reconnecte tout seul en quelques secondes. Votre personnage n'est jamais perdu. |
| Je ne peux pas bouger mon pion | Ce n'est pas votre tour, ou la phase ne permet pas de bouger (Dialogue, Repos), ou vous allez trop loin. |
| Je n'entends pas la musique | Onglet **Groupe** → réglage de la musique. Le MJ doit aussi avoir coché « Jouer aussi sur les téléphones ». |

Pour les détails techniques (réseau, pare-feu), voir `RESEAU.md`. Pour toutes les fonctions, voir `GUIDE_DE_JEU.md`.
