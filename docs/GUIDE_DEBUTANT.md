# Guide du débutant — LEGENDERS RPG

Ce guide est fait pour quelqu'un qui **n'a jamais joué à un jeu de rôle**. Pas besoin de connaître Donjons & Dragons : en 10 minutes de lecture, vous pouvez lancer votre première partie. Le jeu contient aussi une aide intégrée (*Menu › Comment jouer ?*).

---

## 1. C'est quoi, ce jeu ?

C'est une **histoire que l'on raconte à plusieurs**, comme un film dont vous êtes les héros.

- **Un joueur est le Maître du Jeu (MJ).** Il joue sur le PC. Il décrit le monde (« Vous arrivez devant une auberge en ruine, il pleut… »), fait parler les personnages qu'on rencontre, place les monstres et décide de ce qui arrive.
- **Les autres sont les joueurs.** Chacun joue sur son téléphone et incarne **un personnage** qu'il a créé : un guerrier, une assassin, un mage…
- **Il n'y a pas de bouton « gagner ».** Le but est de vivre une aventure ensemble : explorer, discuter, se battre, accomplir des quêtes, devenir plus fort.
- **Le jeu fait tous les calculs** : dés, dégâts, soins, points de vie, expérience, butin. Vous, vous racontez ce que fait votre personnage.

La règle d'or : **vous pouvez tenter n'importe quoi**. Si aucun bouton ne correspond à votre idée, écrivez-la. Le MJ décide comment ça se passe.

---

## 2. Ce qu'il vous faut

- Un **PC Windows** (pour le MJ) avec le jeu installé. Un téléphone Android peut aussi héberger, mais le PC est plus confortable.
- Un **téléphone Android** par joueur, avec l'application installée.
- **Le même Wi-Fi pour tout le monde.** (La 4G ne marche pas : il faut être sur le même réseau.)
- Compter **1 h 30 à 3 h** pour une partie.

---

## 3. Lancer la première partie (5 minutes)

### Le MJ, sur le PC
1. Ouvrez le jeu → **Héberger une partie**.
2. Dans **Nouvelle campagne**, donnez un nom, choisissez un **univers** (« Fantasy classique » pour commencer : il contient une petite aventure prête, *Les Cendres de Valombre*), puis **Créer la campagne et ouvrir la partie**.
3. Si Windows demande l'autorisation du pare-feu : acceptez pour les **réseaux privés**.
4. En haut à gauche, la carte **Pour rejoindre** affiche une **adresse IP** en grand (par exemple `192.168.1.20`). Donnez-la aux joueurs.

### Chaque joueur, sur son téléphone
1. Ouvrez le jeu → **Rejoindre une partie**.
2. Si la partie apparaît dans **Parties sur ce Wi-Fi**, touchez-la. Sinon, tapez votre **nom** puis l'**adresse IP** donnée par le MJ avec le pavé numérique, et touchez **Rejoindre la partie**.
3. Créez votre personnage (voir la section suivante).
4. Vous arrivez dans le salon **« Vous êtes prêt ! »** : attendez les autres.

### Le MJ lance
Quand la barre du haut indique que tout le monde est prêt, le MJ appuie sur **« La partie commence ! »**. C'est parti.

---

## 4. Créer son personnage (5 étapes)

Le jeu vous guide. Si vous hésitez, prenez les choix proposés par défaut : ils sont équilibrés.

**Étape 1 — Qui es-tu ?** Un nom et un visage : touchez les flèches pour changer la coiffure, les yeux, le teint… (ou *Au hasard*). Une couleur de pion. L'histoire et la personnalité sont facultatives.

**Étape 2 — La classe.** C'est le « métier » de votre personnage. Touchez une classe pour voir ce qu'elle sait faire.

| Si vous aimez… | Prenez | Difficulté |
|---|---|---|
| foncer et encaisser les coups | **Guerrier** | facile |
| protéger vos amis | **Gardien** | facile |
| soigner et aider | **Soigneur** | facile |
| frapper vite et faire des critiques | **Assassin** | moyenne |
| tirer à l'arc de loin | **Rôdeur** | moyenne |
| lancer des sorts puissants | **Mage** | moyenne |
| parler, charmer, encourager le groupe | **Barde** | moyenne |

(L'univers Légenders propose ses propres classes : Briseur, Ombre, Invocateur, etc.)

Chaque classe a :
- un **passif** : un bonus qui marche tout seul (ex. le Guerrier devient plus résistant quand il est blessé) ;
- **trois capacités** : ses coups spéciaux, sorts ou techniques ;
- un **ultime** : une capacité très puissante, utilisable quand sa jauge est pleine.

**Étape 3 — Les points.** Votre personnage a 6 caractéristiques, chacune à 5 au départ. Plus le chiffre est haut, meilleur il est :

| Caractéristique | En clair |
|---|---|
| **Force** | taper fort au corps à corps, porter, enfoncer une porte |
| **Dextérité** | viser juste, esquiver (votre Défense), être discret, tirer |
| **Constitution** | avoir beaucoup de points de vie, résister aux coups |
| **Intelligence** | lancer des sorts de savoir, comprendre, résoudre des énigmes |
| **Esprit** | volonté, mana, résister à la magie, bien soigner |
| **Charisme** | convaincre, intimider, renforcer ses alliés |

Vous avez **15 points** à répartir avec les boutons **−** et **+** (jamais moins de 1 ni plus de 10). Pas d'idée ? Touchez **Répartition conseillée**. Les points de vie, la Défense, etc. s'affichent en direct en bas.

**Étape 4 — L'équipement.** Choisissez votre arme parmi celles de votre classe (par exemple l'Assassin choisit parmi trois dagues). Chaque objet indique ses **dégâts**, sa **portée** (en cases) et son **critique** (le résultat de dé qui double les dégâts).

**Étape 5 — Le récapitulatif.** Vérifiez tout. Vous pouvez revenir en arrière. Touchez **Créer mon personnage**.

## 5. L'écran de jeu

```
┌───────────────────────────────┐
│ Lieu · situation · objectif   │  ← en haut : où vous êtes, ce qui se passe
├───────────────────────────────┤
│   [ Récit ]   [ Carte ]       │  ← basculez entre l'histoire et la carte
│                               │
│   l'histoire, ou la carte     │
│                               │
├───────────────────────────────┤
│ Portrait  PV ████████ 40/40   │  ← toujours visible
│           Mana ██████ 26/26   │
│ [cap1][cap2][cap3][ULT] Sac Fiche Journal │
└───────────────────────────────┘
```

- **En haut** : le nom du lieu, la situation (« Combat · tour 2 · à vous de jouer ! ») et votre **objectif** de quête. Touchez l'objectif pour ouvrir le journal.
- **Au centre** : le **Récit** (l'histoire racontée par le MJ, les messages, les résultats) ou la **Carte** (le plateau avec les pions, comme un Monopoly).
- **En bas, toujours visible** : votre portrait, vos **PV** (rouge), votre **mana** ou énergie (bleu), la jauge d'**ultime** (or), vos **capacités** et trois boutons :
  - **Sac** : vos objets et le coffre du groupe ;
  - **Fiche** : tout votre personnage (et vos montées de niveau) ;
  - **Journal** : vos quêtes, le groupe, l'encyclopédie du monde, les réglages.

Les panneaux s'ouvrent par-dessus le jeu : touchez la croix ou l'extérieur pour les fermer.

## 6. Comment on joue

### Parler et agir (Récit)
En bas du Récit, trois modes :
- **Message** : parler au groupe, ou **au MJ en privé** (les autres ne le voient pas).
- **Action** : décrire ce que vous tentez. *Exemples : « Je fouille le bureau du maire », « J'essaie de convaincre le garde de nous laisser passer ».* Les boutons **Examiner**, **Fouiller**, **Parler à…**, **Se cacher**, **Écouter** commencent la phrase pour vous, mais vous pouvez écrire ce que vous voulez. Le MJ répond, et vous demande parfois de **lancer un dé** (un grand bouton apparaît).
- **Dés** : lancer des dés vous-même si le MJ vous le demande.

Parler ne coûte rien : vous pouvez discuter à tout moment, **même pendant un combat**.

### Les phases de jeu
Le MJ choisit le rythme de la partie. Il est écrit en haut de l'écran.

| Phase | Ce qui se passe |
|---|---|
| **Récit libre** | Tout le monde agit quand il veut. |
| **Exploration** | Chacun son tour : on avance son pion, on décrit ce qu'on fait, puis **Terminer mon tour**. |
| **Dialogue** | Chacun son tour, sans bouger. |
| **Combat** | Chacun son tour, dans l'ordre de rapidité (l'« initiative »). |
| **Repos** | On récupère : à la fin, chacun regagne la moitié de ses PV et toute sa mana. |

Quand c'est à vous, **votre téléphone vibre** et affiche **« C'est votre tour ! »**.

### Votre tour de combat, pas à pas
En haut de la carte, la **frise** montre qui joue maintenant (encadré doré) et qui suit, avec leurs PV.

Vous avez **2 points d'action (PA)** par tour :

| Action | Coût |
|---|---|
| Se déplacer (cases dorées) | 1 PA |
| Attaque rapide | 1 PA |
| Attaque puissante (moins précise, +50 % de dégâts) | 2 PA |
| Se défendre (+3 Défense jusqu'à votre prochain tour) | 1 PA |
| Utiliser un objet (potion…) | 1 PA |
| Capacité | indiqué sur la capacité |
| Parler, discuter | gratuit |

Pour attaquer : touchez **Attaque rapide**, puis la cible **entourée de rouge**. Le jeu lance le dé et calcule tout : les dégâts apparaissent en **rouge** au-dessus du pion, les soins en **vert**.

Pour une capacité : touchez-la dans la barre du bas. Le panneau explique ce qu'elle fait, ce qu'elle coûte, et **pourquoi elle est indisponible** si c'est le cas (pas assez de mana, en recharge, ultime pas encore chargé…). Puis **Utiliser** et choisissez la cible.

Quand vous avez fini : **Terminer mon tour**.

### Les dés, en 30 secondes
- `d20` = un dé à 20 faces (résultat de 1 à 20). `2d6` = deux dés à 6 faces additionnés. `+3` = on ajoute 3.
- Pour **toucher** un ennemi, il faut atteindre sa **Défense** (d20 + votre caractéristique).
- Pour **réussir** quelque chose de difficile, il faut atteindre un nombre : 10 facile, 15 moyen, 20 très dur.
- **20 naturel** : réussite automatique (et coup critique). **1 naturel** : échec automatique.
- **Critique** : les dés de dégâts sont doublés.
- Les dés sont lancés par le PC du MJ : personne ne peut tricher.

### Les points de vie (PV)
Quand vous êtes touché, vos PV baissent. À **0 PV**, votre personnage est **hors de combat** (son pion devient gris). Il n'est pas forcément mort : c'est le MJ qui raconte la suite. Le repos, les potions et les soins font remonter les PV.

### Effets
Certains coups provoquent des **effets** (petites icônes au-dessus des pions et sur votre fiche) : *étourdi* (perd son tour), *empoisonné* (perd des PV chaque tour), *immobilisé*, *bouclier* (absorbe des dégâts), *renforcé* (+2 dégâts)… La fiche explique chacun d'eux.

## 7. Progresser

- **Victoire** : quand tous les ennemis sont à terre, le jeu donne l'**XP** et l'**or**, et le **butin** arrive dans le **coffre du groupe** (Sac › Coffre du groupe). Mettez-vous d'accord, puis touchez **Prendre**.
- **Quêtes** : le MJ vous confie des quêtes (principales ou secondaires). Elles apparaissent dans le **Journal**, avec leurs objectifs et leur récompense. Une quête réussie rapporte XP, or ou objets.
- **Niveau supérieur** : un **+** doré apparaît sur votre portrait. Ouvrez votre **Fiche** :
  - placez **1 point** dans la caractéristique de votre choix ;
  - **apprenez une nouvelle capacité** de votre classe, ou **améliorez** une capacité que vous avez déjà (plus de dégâts, moins chère).
- **Objets** : dans le Sac, touchez un objet pour le voir. Le jeu montre ce qui change si vous l'équipez (*Défense 12 → 16*). Les **raretés** se reconnaissent à la couleur : gris (commun), vert (peu commun), bleu (rare), violet (épique), or (légendaire). Un **livre de compétence** s'utilise avec *Lire* pour apprendre une capacité.
- Vous connaissez plus de capacités que vous ne pouvez en équiper (3 + l'ultime) : choisissez celles de votre barre dans la **Fiche**.

## 8. Guide express du MJ

Vous n'avez pas besoin d'être un conteur professionnel. Voici une recette pour une première soirée réussie.

### Votre écran
- **À gauche** : comment rejoindre (adresse IP) et les joueurs, avec leurs PV et leur mana. *Fiche et outils* ouvre tout ce que vous pouvez faire sur un personnage.
- **Au centre** : la **Carte** et le **Récit**.
- **À droite** : les outils — **Combat** (phases, tours, monstres), **Monde** (cartes, musique, dessin), **Quêtes**, **Créer** (objets, capacités, effets, monstres, classes, butin, règles), **Fiches**, **Codex**, **Réseau**.
- **En bas** : votre saisie. Avec **Narration** coché, vos textes s'affichent comme un récit ; décochez pour un simple message. Le menu **Événement rapide…** propose : épreuve de groupe, dégâts ou soins de groupe, récompense de groupe, embuscade, créer un objet, nouvelle quête.

### Avant de commencer (10 minutes)
- Univers **Fantasy classique** : la carte de Valombre, ses habitants et ses secrets sont prêts.
- Dans **Quêtes**, préparez une **quête principale** en brouillon (titre, objectifs, récompense : XP, or, objet).

### Pendant la partie
1. **Ouvrez la scène** avec une narration : « Vous arrivez à Valombre à la tombée de la nuit. Les cloches sonnent alors qu'aucune messe n'est prévue… »
2. **Donnez la quête** (bouton *Donner aux joueurs*) : elle s'affiche chez tout le monde.
3. **Répondez aux actions** : elles apparaissent en haut du Récit. Résolvez-les, refusez-les, ou cliquez **« Le joueur lance »** pour lui demander un dé.
4. **Pour un combat** : *Événement rapide › Embuscade* (choisissez des monstres, le combat démarre tout seul), ou *Créer › Monstres › Placer*, puis la phase **Combat**. Quand c'est le tour d'un monstre, la carte **Phase de jeu** propose ses attaques et capacités, ou **Jouer automatiquement**.
5. **Après la victoire** : XP, or et butin sont distribués tout seuls. Passez en **Repos** ou en **Récit libre**.
6. **Quête accomplie** : *Réussie : distribuer*. Les récompenses sont données une seule fois.

### Improviser
- Un joueur trouve un trésor inattendu ? *Créer un objet* (nom, rareté, effets) puis donnez-le directement.
- Un piège ? *Dégâts ou soins de groupe*. Une falaise à escalader ? *Épreuve de groupe* (Dextérité, difficulté 15).
- Une idée que le jeu ne prévoit pas ? Racontez-la, et utilisez *Fiche et outils* pour appliquer les conséquences (PV, effets, objets, XP…). Tout ce que vous modifiez à la main est noté dans votre journal du MJ.

### Trois conseils
- **Dites « oui, mais… »** plutôt que « non ». Un joueur veut sauter par la fenêtre ? D'accord, mais il se blessera peut-être (jet de dé).
- **Donnez la parole à tout le monde**, surtout aux plus timides.
- **Ne vous bloquez pas sur les règles.** Si vous hésitez, décidez et continuez : l'histoire compte plus que le calcul.

## 9. Petit lexique

| Mot | Sens |
|---|---|
| **MJ** | Maître du Jeu : celui qui raconte et arbitre. |
| **PNJ** | Personnage Non Joueur : tous les personnages joués par le MJ (aubergiste, méchant…). |
| **PV** | Points de Vie. |
| **Mana / AEC / Vigueur** | La réserve qui sert à utiliser les capacités (son nom dépend de la classe). |
| **PA** | Points d'Action : ce que vous pouvez faire pendant votre tour (2 par défaut). |
| **Défense** | Le nombre à atteindre au dé pour vous toucher. |
| **Initiative** | Votre rapidité : elle décide qui joue en premier en combat. |
| **Passif** | Bonus de classe qui marche tout seul. |
| **Ultime** | Capacité très puissante, utilisable quand sa jauge est pleine. |
| **Recharge** | Nombre de tours à attendre avant de réutiliser une capacité. |
| **Critique** | Coup particulièrement réussi : dés de dégâts doublés. |
| **XP** | Expérience : en accumuler fait monter de niveau. |
| **Butin** | Objets et or récupérés après un combat ou une quête. |

## 10. Problèmes fréquents

| Problème | Solution |
|---|---|
| « Le PC du MJ ne répond pas » | Vérifiez que le téléphone est sur **le même Wi-Fi** que le PC (pas en 4G) et que l'adresse IP est bien recopiée. Sur le PC, autorisez le jeu dans le pare-feu Windows (réseaux privés). |
| « Version du jeu différente » | Le PC et le téléphone n'ont pas la même version : réinstallez la bonne. |
| Le téléphone a perdu la connexion | Il se reconnecte tout seul en quelques secondes. Votre personnage n'est jamais perdu. |
| Je ne peux pas bouger mon pion | Ce n'est pas votre tour, plus de PA, vous êtes immobilisé, ou la phase ne permet pas de bouger (Dialogue, Repos). |
| Ma capacité est grisée | Touchez-la : le panneau explique pourquoi (mana, recharge, ultime pas chargé, pas votre tour). |
| Je n'entends pas la musique | *Journal › Réglages*. Le MJ doit aussi avoir coché « Jouer aussi sur les téléphones ». |

Pour les détails techniques (réseau, pare-feu), voir `RESEAU.md`. Pour toutes les fonctions, voir `GUIDE_DE_JEU.md`.
